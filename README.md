# Pre-entrega---Modulo-8
Pre-entrega: Modelo de datos con relaciones activas y tabla de medidas core en DAX

----------------------------------------------------------------------------

La relación entre Dim_Categorias y Dim_Productos se estableció por el campo de texto categoria/nombre_categoria, ya que Dim_Productos no cuenta con una columna id_categoria en el dataset provisto. Funcionalmente es equivalente: ambas columnas tienen cardinalidad única por categoría y garantizan la misma integridad referencial.
